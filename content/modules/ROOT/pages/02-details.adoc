== What you need

[cols="1,2",options="header"]
|===
| If you are… | You need

| Every participant
| A browser, the OpenShift console URL and the user name and password your facilitator gave you.
All commands run in the console's Web Terminal, as you.

| Using your own laptop shell instead (optional)
| `oc` matching the cluster (download it from the console: *?* → *Command Line Tools*), `curl`
and `jq`; log in with *Copy login command* from the user menu.
|===

Provided by the facilitator:

* A dedicated OpenShift {ocp_version} cluster with OpenShift AI {rhoai_version}, one GPU node with
  an NVIDIA L4, and the workshop operators installed by OpenShift GitOps.
* Your user, a cluster administrator on this cluster.

== Log in

. Open the OpenShift console:
  link:https://console-openshift-console.{cluster_domain}[console-openshift-console.{cluster_domain}^].
. Choose the identity provider your facilitator named (on the test cluster, *keycloak*) and log in
  with your user and password.
. Check the user menu (top right).

Expected result: the console opens on *Overview* with *Core platform* at the top of the left
navigation, and the user menu (top right) shows your name, for example `Kuro Admin`.

The command-line pre-flight is the first exercise of
xref:03-module-01-your-cluster.adoc[Module 1], run in the Web Terminal.

== Why there is no terminal in this guide

The Showroom page you are reading has no login. A terminal embedded here would run with the rights
of whoever deployed it, available to anyone with the URL. Your user is a cluster administrator, so
you work in the console's Web Terminal instead, which runs as you after you log in.
