== Evidence interpretation

[cols="1,2,2",options="header"]
|===
| Topic | Supported interpretation | Required evidence

| GPU usable on the node
| the kernel driver is loaded and sees the GPU
| `NVIDIADriver` state `ready` and `nvidia-smi` naming the GPU

| GPU schedulable
| the scheduler can allocate the device to claims
| a `ResourceSlice` listing the device, and a claim allocated to it

| Exclusive allocation
| a template gives each pod its own device
| a second pod `Pending` with `cannot allocate all claims`

| Shared allocation
| pods referencing one claim use the same device
| the same GPU UUID in both pods; `reservedFor` lists both

| Model provenance
| the deployed image is a recorded version
| the registry's artifact URI equals the InferenceService `storageUri`

| Endpoint protection
| only callers with a token and RBAC are answered
| 401 anonymous, 403 for an identity without `get` on the InferenceService, 200 for an authorised one
|===

== What this lab does not prove

* *Support status of the DRA path.* OpenShift AI {rhoai_version} documents GPU access through the
  device plugin and hardware profiles. The `GPUCluster` API is `v1alpha1` in GPU Operator
  {gpu_operator_version}, and requesting the GPU with `resourceClaims` in an InferenceService is
  accepted by the KServe API but is not a documented OpenShift AI procedure. The labs teach the
  mechanism; they do not establish a supported configuration.
* *Isolation of shared GPUs.* Pods that share a claim share GPU memory and compute without
  isolation. Use MIG or a supported sharing mode where isolation matters.
* *Performance.* One L4 per cluster demonstrates mechanisms; it does not predict latency or
  throughput on production hardware.
* *Automatic registry-to-deployment linkage.* The registry does not watch the cluster: the
  InferenceService's registry labels alone left the dashboard's *Deployments* column at `-`. Module 3
  records the deployment explicitly through the registry API (serving environment and inference
  service), after which the dashboard shows `1 deployment`.
